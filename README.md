# 四个小游戏：Rust 跨平台版

## 构建

需要 Rust 工具链（rustc 1.70+，使用 stable 即可）：

```bash
cd cross_platform_games
cargo build --release
```

产物在 `target/release/` 下：`minesweeper`、`chinese_chess`、`escape_school_81`、`escape_school_cracked`。

## 运行

直接在终端中运行对应可执行文件即可：

```bash
./target/release/minesweeper
./target/release/chinese_chess
./target/release/escape_school_81
./target/release/escape_school_cracked
```

- 扫雷、中国象棋默认使用**鼠标交互**（需支持鼠标捕获的终端）；传 `--legacy` 参数可退回原有的「输入坐标」文字交互。
- 逃离学校两个版本需要 **实时按键（原始模式）**，请在真正的终端（Windows Terminal / macOS 终端 / Linux 终端）中运行，不要通过某些不支持 TTY 的远程工具运行。
- 开始游戏前请将输入法切换到英文。

## 1. 扫雷（minesweeper）

原版 `其他/扫雷.txt`，10×10 棋盘。

- **难度**：1~5，地雷数 = 10 × 难度。
- **操作（默认鼠标模式）**：**左键**翻开格子，**右键**标记/取消标记地雷，`q` 退出。
- **操作（`--legacy` 文字模式）**：输入「行 列」翻开格子；行/列后加 `p` 标记地雷（如 `1 2p`）；`q` 退出（原版 README 声称 q 退出但代码未实现，现已修复，两种模式均生效）。
- 翻开后显示相邻地雷数，踩雷失败，全部安全格翻开即胜利。
- 随机数使用自实现的 xorshift64（不依赖平台随机 API），保证跨平台一致。

## 2. 中国象棋（chinese_chess）

原版 `其他/中国象棋.txt`（2657 行增强 AI 版）。

- **功能**：完整中国象棋规则（马走日、象走田、车直线、炮隔山打牛、兵过河、九宫格、飞将），Minimax + Alpha-Beta 剪枝 + 静态搜索（Quiescence）+ 迭代深化 + Zobrist 哈希 + 免送棋评估。
- **模式**：玩家 vs 玩家 / 玩家 vs AI / AI vs AI。
- **操作（默认鼠标模式）**：
  - **左键**点击己方棋子选中（该棋子变**紫色**，可落点出现棋子字样并呈**蓝色**）；
  - 点击蓝色落点即走子；点击己方其他棋子可**切换选择**；再点同一枚取消选择；
  - **右键**取消选择；`q` 退出、`r` 重开。
- **操作（`--legacy` 文字模式）**：输入「行 列 行 列」（如 `9 4 7 4` 表示炮二平五）；特殊命令 `99 0`~`99 9` 查看帮助、评估、历史、重开、退出、切换 AI 难度、规则、局面信息、清空历史、AI 技术说明。
- **修复的原版 bug**：原版用 `std::unordered_set` 记录重复局面，导致「三次重复」计数恒为 1、和棋规则永不触发；本版改用计数表（HashMap），三次重复局面真正判和。
- **修复的未定义行为**：原版棋子直接落到目标格会覆盖/移动敌方棋子，本版走子前先做合法性校验，非法走子会被拒绝。

## 3. 逃离学校 8.1（escape_school_81）

原版 `逃离校园相关程序/8.1.txt`（1246 行实时按键游戏）。

- **剧情**：深夜从宿舍出发，躲过宿管/老师/保安/校长的追逐，集齐「宿舍门禁卡 → 体育办公室钥匙 → 图书馆钥匙」逃出学校。
- **操作**：
  - `WSAD` 移动（`W/S` 只能走空地，`A/D` 可上下床）
  - `1/2/3` 切换走路/跑步/疾跑（疾跑耗体力）
  - `Q` 存档（运动状态无法存档，停下后再存）
  - 失败后提示回档（Y/N），选择存档恢复
  - 结束后可选择生成「你的游戏过程.cpp」回放文件（生成的是跨平台 ANSI 版 C++，不再依赖 windows.h）
- 5 张地图（宿舍房间 → 走廊 → 大厅 → 校园 → 图书馆），NPC 有不同警觉范围（宿 3、师 3、保 5）。
- **修复的原版未定义行为**：地图4→地图3、地图5→地图4 的返回落点原版未定义（未初始化变量），本版给出合理落点（实际游戏中这两个路径不可达，仅作防御）。

## 4. 逃离学校-改编版（escape_school_cracked）

原版 `逃离校园相关程序/全新破解版.txt`（1193 行，8.1 的改编版）。

- 比 8.1 多：**主菜单**（1 开始 / 2 退出）、**彩色地图渲染**（按原版 Windows 控制台色号 0~15 映射为 ANSI 颜色：床=蓝、墙=白、NPC=红、大门=绿、体力=亮黄等）、**彩蛋**。
- **彩蛋**（开场白逐字显示时输入）：
  - 输入 `pl` → 不会被任何 NPC 抓住（体力仍会耗尽）
  - 输入 `jmd` → 无敌模式（可穿墙移动、体力不减）
- 存档/回档在菜单中完成（选「开始游戏」前会询问是否回档）。
- 胜利判定、生成回放文件与 8.1 相同。

## 跨平台说明

| 原版（C++）                        | 本版（Rust）                                     |
| ---------------------------------- | ------------------------------------------------ |
| `windows.h` / `GetAsyncKeyState`   | crossterm 原始模式 + 事件轮询（三平台一致）        |
| `system("cls")`                    | ANSI `\x1b[2J\x1b[H`（Windows 10+ 自动启用）      |
| `SetConsoleTitle`                  | ANSI OSC `\x1b]0;...\x07`                        |
| `Sleep(ms)`                        | `std::thread::sleep`                             |
| Windows 控制台色号 0~15            | `gamekit::color::win_color` 映射为 ANSI 16 色     |
| 生成的回放 C++（依赖 windows.h）   | 生成的回放 C++ 用 ANSI + `<thread>`（跨平台编译） |
| 文本坐标输入                        | `gamekit::MouseMode` 鼠标捕获（扫雷/象棋默认启用） |

## 与原版的其他差异

- 原版 C++ 源文件里依赖 `conio.h` / `windows.h` / 未初始化变量等平台与未定义行为，本版全部消除；
- 游戏逻辑（地图布局、NPC 移动规则、体力结算、存档字段、判定阈值）与原版逐条对齐；
- 所有输出均使用 UTF-8 中文，无需修改终端代码页；
- 扫雷、中国象棋新增鼠标交互（`--legacy` 可退回文字输入）；扫雷修复了原版 `q` 退出无效的问题。
